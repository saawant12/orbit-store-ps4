# Find, download and install DLC

**For Orbit Store 0.2.0 for PS4.**

The catalogue has **564 add-ons for 125 games**, with **566 download options**. These are counted separately from base games.

**Want the game, its update and all its DLC?** From **0.1.0**, choose **Get everything** on the game’s page. Orbit adds them to Downloads in one go, then installs them in order: the game, then the update, then the DLC. See [Get everything](downloads.md#get-everything).

## Find add-ons

Open **Add-ons**, after **Browse** in navigation, or choose **Add-ons (count)** on a game’s details page to see its extras. The page works in the TV app, the browser and [Orbit Zero](orbit-zero.md), in Store, Crossbar, Cinema and Panorama. With a PS4 paired, Orbit Zero lists PS4 add-ons only.

Search by the DLC name or base-game name. Filter by **Type**, **Source** and **Region**; **Recently added** is the default order. Enabled source settings also apply to add-ons.

Each tile identifies the add-on, its base game and its type. When separate DLC artwork is unavailable, Orbit uses the base game’s artwork.

## Understand the type

| Type | What it provides |
| --- | --- |
| **Expansion** | A campaign or substantial extra content. |
| **Content pack** | Extra items, characters, missions or other content. |
| **Activation package** | Unlocks content already present in the base game. It doesn’t contain that content. |
| **Bundle** | Several add-ons or packages together. Check the details for known contents. |

## Check the required game

Before downloading, review the base-game edition, title ID, region and any known version requirements. A matching title ID alone doesn’t confirm compatibility.

If a requirement is unknown or Orbit can’t detect a matching base game, it explains that and still allows downloading. You can save the DLC for later, but confirm the requirements before installing it. Orbit doesn’t fetch missing game updates automatically.

Seeing a base game in Library doesn’t mark its DLC as installed. Likewise, an add-on included in one edition or bundle isn’t necessarily included in another download option.

## Download and install

Open the add-on and choose a source and drive in the usual download options. Archive.org sign-in, Vikingfile sign-in, TorBox for supported sources, provider verification, archive passwords and download recovery work as they do for games.

Downloads identify both the base game and add-on, for example **Cuphead · The Delicious Last Course · DLC**. ZIP, RAR and 7z files unpack on the selected PS4 drive, or on the computer before Orbit Zero sends them.

In Orbit Zero, choose **This computer** to download without a connected PS4. Later, connect your PS4 and choose **Send to PS4**. See [Orbit Zero](orbit-zero.md#download-now-and-send-to-your-ps4-later).

When the download finishes, open it in **Downloads** and choose **Downloaded files** or **Install on PS4**. Review the base-game requirements again, select the package and choose **Install on PS4**.

For a bundle, choose each package you want to install. Orbit doesn’t install the whole bundle automatically or choose an installation order. Downloaded packages are kept by default. The optional **App settings → Storage & cleanup → Installed packages** setting can delete each package after it installs successfully; see [installing games](install-games.md). Installing doesn’t change firmware or jailbreak requirements.

Downloading and installing have separate progress. See [installing games](install-games.md) for installation status, storage and recovery.

## If an add-on is missing

Check your enabled sources and clear the Add-ons filters. If you opened the page from a game’s details, it shows extras for that game only; go back to all add-ons to browse everything. Refresh the catalogue in settings to check for additions.

For a problem report, include the add-on, selected source and format, the base game’s title ID and version, and the exact error.
