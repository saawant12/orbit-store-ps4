# Manage files on your PS4

**For Orbit Store 0.2.0 for PS4.**

Open **Library → Files** in the TV app, the browser or [Orbit Zero](orbit-zero.md) on a paired computer. Choose internal storage or a connected USB drive. Each drive shows its free space.

![Files in the PS4 TV app: Internal storage with folders, dates and a … button for each folder's actions](../assets/0.0.1/native-files.jpg)

*Files in the PS4 TV app. Select a folder to open it; use its … button for actions.*

## Browse folders and choose actions

Select a folder to open it. **Circle** or **Escape** returns to its parent folder, then the drive list, then Library. An open dialog or menu closes before you leave the folder. **Up one folder** and **All drives** are also available on screen.

In Store and Cinema, use the folder row’s **…** button for its actions; selecting a file opens its details and actions. Crossbar keeps actions in the selected row’s menu. Panorama shows the selected entry’s actions beside the folder tiles. Search applies to the open folder, with sorting by name, size or date.

Files shows ordinary files and folders, including packages and archives. Hidden and system entries and Orbit’s own working files are left out. It doesn’t follow symbolic links. Folders with more than 2,000 visible entries show the first 2,000.

## Copy, move, rename and delete

- **Copy** or **Move:** choose the item, go to the destination folder, then select **Paste here**. Copy keeps the original. Move removes it only after the copy succeeds; a move within one drive may finish immediately.
- **New folder** or **Rename:** enter the name. Existing names aren’t overwritten.
- **Delete:** check the path and confirm. This deletes the file or folder, not an installed PS4 game, and can’t be undone.
- **Measure size:** totals a folder’s contents.

File operations run one at a time. Copy and move have pause and resume controls; operations other than installations can be cancelled while they run. Cancelling can’t undo files already deleted or a move that already finished. A copied file or folder appears at its destination only when copying completes.

Downloads can continue, start or resume while you change files. Orbit keeps enough space for both, and a download can’t start under a name a file operation is using. Orbit also protects its settings, files used by downloads or the installer, and games installed on the PS4. If a source changes during copying, Orbit stops instead of keeping an incomplete copy or deleting the original.

## Unpack and install

**Unpack here** supports ZIP, RAR and 7z. Orbit tries its known passwords, then asks for a password if needed. Files keeps the original archive. Existing unpacked items aren’t overwritten.

**Install on PS4** uses the console’s package installer for PKG and FPKG files. Installation still depends on the game, firmware and jailbreak. See [installing games](install-games.md).

## Save a file to another device

On a paired phone or computer, **Save to this device** downloads the selected file. In Orbit Zero, **Save to this computer** saves it in the computer’s download folder; an existing file there is kept and the new copy gets a numbered name. The PS4’s own browser and the TV app don’t offer this action.
